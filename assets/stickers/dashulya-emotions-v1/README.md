# Dashulya: emotions v1

Six static Telegram stickers based on [Dashulya's avatar](../../avatar-original.png).

| File | Emotion | Suggested emoji |
| --- | --- | --- |
| 01-joy | Joy | 😄 |
| 02-love | Love / air kiss | 😘 |
| 03-sad | Sadness | 😢 |
| 04-angry | Anger | 😠 |
| 05-surprised | Surprise | 😮 |
| 06-skeptical | Skepticism | 🤨 |

## Files

- `png/`: six transparent 512 × 512 PNG files.
- `webp/`: the same six stickers as transparent WebP files.
- `sources/`: original generated images before export.
- [PROMPTS.md](PROMPTS.md): exact prompts used with the built-in image_gen tool.
- `dashulya-emotions-v1.zip`: ready-to-upload PNG and WebP files, this guide and the prompts.

The exports meet Telegram's static-sticker dimensions and file-size limits: a 512-pixel side, transparency and less than 512 KB per file. See [Telegram sticker requirements](https://core.telegram.org/stickers) and [import requirements](https://core.telegram.org/import-stickers).

## Create a Telegram pack

Open [@Stickers](https://t.me/Stickers), use `/newpack`, enter a pack name, then upload the six files from either `png/` or `webp/` as files/documents. Send the matching emoji after each sticker and follow the bot's publish instructions.

The files are prepared locally; no Telegram pack has been published.
